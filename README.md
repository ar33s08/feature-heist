# HEIST — we steal that feature. Legally.

Point us at any app you pay for. You get an **evidence-backed teardown** of the
feature you actually love — down to byte offsets in the shipped binary — and a
**clean-room rebuild** of that feature you can run forever.

HEIST is built on [REA](https://github.com/morluto/rea), the open-source
reverse-engineering engine. This repo is the public half: the dossiers.
The private half (your rebuild, priority queue) is the product → heist.tools

## Is this legal?

Yes. We analyze **shipped, lawfully obtained binaries** for interoperability
and understanding (Sony v. Connectix; Sega v. Accolade; Oracle v. Google
narrows actionable copying to expression). We publish no target source code,
assets, or trademarks — dossiers are commentary quoting short excerpts, and
rebuilds are 100% original code written from observed behavior. This is the
same clean-room posture the industry's teardown press takes.

## Run CommandOpen yourself

```bash
swiftc -O -o CommandOpen commandopen/main.swift -framework Cocoa -framework Carbon
./CommandOpen --engine-test   # 7/7 ranking tests against your machine
open -a ./CommandOpen.app     # then press ⌥ Space anywhere
```
